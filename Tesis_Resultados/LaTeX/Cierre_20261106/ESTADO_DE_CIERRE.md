# Estado de cierre científico y editorial

Se preparó una versión revisada para evaluación del asesor. No se declaró una versión final aprobada.

## Correcciones
- Se sustituyeron introducción y resumen ajenos al tema y se desactivó el prefacio vacío, conservando su archivo para el autor.
- Se añadió el alcance operativo a los objetivos sin cambiar su contenido sustantivo.
- Se corrigieron referencias con autoría, año o DOI equivocados. Las entradas no verificadas o ajenas al estudio se retiraron de esta versión; permanecieron recuperables en la revisión anterior.
- Se corrigieron afirmaciones de simulaciones no realizadas: barridos espectrales, motor FDTD propio, validación 3D, directividad medida, mapas SAR, calibración del generador y eficiencia global.
- Se corrigió el factor de acoplamiento entre polarización circular y lineal, la longitud de onda en medios con pérdidas y el signo de la fase de impedancia según la convención temporal.
- Se describió el balance realmente ejecutado sobre cuatro caras de un anillo sin fuentes, distinguiéndolo de dos volúmenes que rodean una fuente.
- Se corrigió la resolución base ficticia de 20 px/mm. Se conservaron resultados, figuras, intervalos y limitaciones medidos.

## Requisitos pendientes para una versión final de entrega
1. El asesor debe evaluar si el alcance homogéneo obtenido satisface el proyecto aprobado. Los objetivos originales de penetración y ajuste de modelos no tienen validación integral con interfaces o datos independientes. No se modificaron retrospectivamente para aparentar cumplimiento.
2. La atribución de parámetros a materiales reales requiere su procedencia experimental o bibliográfica precisa y sus condiciones de medición. En esta versión se identificaron como entradas del programa; no se inventó una fuente ni una incertidumbre material.
3. Para afirmar exactitud de potencias absolutas se requieren refinamientos adicionales y una comprobación temporal más extensa. El cierre local ya medido no suple esas pruebas.
4. Faltan la hoja de firmas y los datos formales de aprobación/examinador. No se incorporaron firmas ni fechas inventadas.

La versión entregada permite revisar las conclusiones dentro del alcance declarado. No prueba rendimiento de una red 5G, seguridad de exposición, SAR o eficiencia global de antena.
